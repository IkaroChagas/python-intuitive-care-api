## English

### Overview

This repository contains the Python back end responsible for reading and processing data from a CSV file and exposing a RESTful API for consumption by the front end (built in VueJS: https://github.com/IkaroChagas/vue-intuitive-care-front).

### Prerequisites

- **Python** ≥ 3.10.x  
- **Dependencies:** install via  
  ```bash
  pip install -r requirements.txt
  ```  
- (Optional) Virtual environment (`venv` or `virtualenv`)

### Installation & Running

1. **Clone the repo**  
   ```bash
   git clone https://github.com/IkaroChagas/python-intuitive-care-api.git
   cd python-intuitive-care-api
   ```
2. **Install dependencies**  
   ```bash
   pip install -r requirements.txt
   ```
3. **Run the API**  
   ```bash
   python app.py
   ```
   By default, the server will listen on `http://localhost:8000`.
